Learning objectives

  • Decide whether \(f(x) = 0\) has a root in an interval, and recognize simple and multiple roots.
  • Measure how sensitive a root is to errors in \(f\) (its condition number), and say what accuracy to expect.
  • Define the convergence rate \(r\) and constant \(C\) of an iterative method, and read them from a sequence of errors.
  • Run the bisection method by hand, and predict how many steps it needs.
  • Set up a fixed-point iteration \(x_{k+1} = g(x_k)\), decide whether it converges, and at what rate.

1. Nonlinear equations; existence and multiplicity (Heath §5.1–5.2)

Given a continuous \(f: \mathbb{R} \to \mathbb{R}\), we look for a root (zero) \(x^*\) with \(f(x^*) = 0\). Unlike \(Ax = b\), a nonlinear equation may have no solution, one, several or infinitely many, and there is usually no formula: we compute approximations \(x_0, x_1, x_2, \ldots\) and stop when they are good enough.

  • Bracket: if \(f\) is continuous on \([a, b]\) and \(f(a)\) and \(f(b)\) have opposite signs, the Intermediate Value Theorem guarantees a root in \((a, b)\). This is the starting point of bisection.
  • Multiplicity: \(x^*\) is a simple root if \(f'(x^*) \ne 0\). It is a multiple root of multiplicity \(m\) if \(f(x^*) = f'(x^*) = \cdots = f^{(m-1)}(x^*) = 0 \ne f^{(m)}(x^*)\). At a double root the graph touches the axis without crossing it, so there is no sign change to bracket.

Example

Example 1. Show that \(e^{-x} = x\) has a root in \([0, 1]\). Is it simple?

Answer

Let \(f(x) = e^{-x} - x\). It is continuous, \(f(0) = 1 > 0\) and \(f(1) = e^{-1} - 1 \approx -0.632 < 0\), so a root lies in \((0, 1)\). Since \(f'(x) = -e^{-x} - 1 < 0\) everywhere, \(f\) is decreasing: the root is unique and simple. (It is \(x^* = 0.567143\ldots\), used in the examples below.)

2. Sensitivity and conditioning (Heath §5.3)

A root-finding problem is the inverse of evaluating \(f\), so its conditioning is the reverse. If \(f\) is steep at \(x^*\), a small error in the function values moves the root very little; if \(f\) is flat, the root is poorly determined. Since \(f(x^*) = 0\), use the absolute condition number \[ \operatorname{cond} = \frac{1}{|f'(x^*)|}, \qquad |\Delta x| \approx \operatorname{cond} \cdot |\Delta f| . \]

  • A multiple root has \(f'(x^*) = 0\): infinite condition number. A tiny change in \(f\) can split it into two roots or remove it.
  • Residual vs error: a small residual \(|f(\hat x)|\) means \(\hat x\) is close to \(x^*\) only if the problem is well conditioned. Near a flat \(f\), \(|f(\hat x)|\) can be tiny while \(|\hat x - x^*|\) is large.

Example

Example 2. \(f(x) = (x - 1)^2\) has a double root at 1. Perturb it to \(f(x) = (x - 1)^2 - 10^{-6}\). Where are the roots now, and what is the condition number of each?

Answer

\((x - 1)^2 = 10^{-6}\) gives \(x = 1 \pm 10^{-3}\). A change of \(10^{-6}\) in the function moved the root by \(10^{-3}\), a thousand times more. At the new roots \(|f'| = 2\cdot10^{-3}\), so \(\operatorname{cond} = 500\). The original double root has \(\operatorname{cond} = \infty\). In double precision, expect only about half the digits of a double root.

3. Convergence rates and stopping criteria (Heath §5.4)

With error \(e_k = x_k - x^*\) (or the bracket length, for bisection), a method converges with rate \(r\) if \[ \lim_{k\to\infty} \frac{|e_{k+1}|}{|e_k|^{r}} = C, \qquad 0 < C < \infty . \]

  • \(r = 1\), \(C < 1\): linear. Each step gains a constant \(-\log_{10} C\) digits.
  • \(r > 1\): superlinear (secant: \(r \approx 1.618\)).
  • \(r = 2\): quadratic. The number of correct digits roughly doubles each step (Newton at a simple root).
  • On a semilog plot of \(|e_k|\) against \(k\), linear convergence is a straight line; superlinear curves downward ever faster.
  • Stopping: we never know \(e_k\). Stop when the step \(|x_{k+1} - x_k|\) or the residual \(|f(x_k)|\) is below a tolerance, preferably relative (\(|x_{k+1} - x_k| \le \text{tol}\,|x_{k+1}|\)), and also after a maximum number of iterations in case the method fails. Neither test alone is safe: think of a flat \(f\) or a steep one.

Example

Example 3. Classify the error sequences (a) 0.5, 0.35, 0.245, 0.1715, … and (b) 0.2, 0.04, 0.0016, 2.56 × 10⁻⁶, ….

Answer

(a) Each error is 0.7 times the previous one: linear, \(C = 0.7\), only about 0.15 digits per step. (b) \(|e_{k+1}| / |e_k|^2 = 0.04/0.04 = 0.0016/0.0016 = 1\): quadratic with \(C = 1\). The exponent of 10 doubles each step.

4. Interval bisection (Heath §5.5.1)

Start with a bracket \([a, b]\), \(f(a)f(b) < 0\). Repeat: \(m = a + (b - a)/2\); keep the half \([a, m]\) or \([m, b]\) on which \(f\) still changes sign. Only the signs of \(f\) are used, so bisection always converges (for continuous \(f\)) but slowly: the bracket halves every step, linear with \(C = \tfrac12\), about one decimal digit every 3.3 steps. To reach a bracket of length tol it needs \[ k = \left\lceil \log_2 \frac{b - a}{\text{tol}} \right\rceil \] steps, whatever \(f\) is. (Computing \(a + (b - a)/2\) instead of \((a + b)/2\) keeps \(m\) inside the bracket in floating point.)

Example

Example 4. Do two steps of bisection for \(f(x) = e^{-x} - x\) on \([0, 1]\). How many steps give a bracket shorter than \(10^{-4}\)? Shorter than \(10^{-8}\)?

Answer

\(m = 0.5\): \(f(0.5) = 0.1065 > 0\), same sign as \(f(0)\), so keep \([0.5, 1]\). \(m = 0.75\): \(f(0.75) = -0.2776 < 0\), so keep \([0.5, 0.75]\). Steps: \(\lceil \log_2 10^4 \rceil = 14\) and \(\lceil \log_2 10^8 \rceil = 27\). Twice the digits costs twice the steps, the mark of linear convergence.

5. Fixed-point iteration (Heath §5.5.2)

Rewrite \(f(x) = 0\) as \(x = g(x)\), with the same solutions, and iterate \(x_{k+1} = g(x_k)\). A fixed point \(x^* = g(x^*)\) is where the graph of \(g\) meets the line \(y = x\). There are many choices of \(g\) for one \(f\), and they behave very differently.

  • Convergence: if \(|g'(x^*)| < 1\) and \(x_0\) is close enough, the iteration converges. By the Mean Value Theorem \(e_{k+1} = g(x_k) - g(x^*) = g'(\theta_k)\,e_k\), so asymptotically it is linear with \(C = |g'(x^*)|\). If \(|g'(x^*)| > 1\) it diverges.
  • Sign of \(g'\): \(g' > 0\) approaches monotonically (a staircase in the cobweb diagram); \(g' < 0\) oscillates around \(x^*\) (a spiral).
  • \(g'(x^*) = 0\): by Taylor's theorem \(e_{k+1} = \tfrac12 g''(\xi)\,e_k^2\): at least quadratic. Newton's method (meeting 18) is the fixed-point iteration built to make \(g'(x^*) = 0\).
  • The error shrinks roughly like \(C^k |e_0|\), a geometric sequence, which lets you estimate the number of steps: about \(\log(\text{tol}/|e_0|)/\log C\).

Examples

Example 5. Iterate \(x_{k+1} = e^{-x_k}\) from \(x_0 = 0.5\). Predict the rate and compare with the computed errors.

Answer

Iterates 0.5, 0.606531, 0.545239, 0.579703, 0.560065, … oscillate around \(x^* = 0.567143\). \(g'(x) = -e^{-x}\), so \(g'(x^*) = -x^* \approx -0.567\): linear with \(C \approx 0.567\), oscillating because \(g' < 0\). The errors 0.0671, 0.0394, 0.0219, 0.0126, 0.0071 have ratios 0.59, 0.56, 0.57, 0.56, matching \(C\).

Example 6. The same equation can be written \(x = -\ln x\). Does \(x_{k+1} = -\ln x_k\) converge to \(x^*\)? What about \(x_{k+1} = \tfrac12\bigl(x_k + e^{-x_k}\bigr)\)?

Answer

For \(g(x) = -\ln x\), \(|g'(x^*)| = 1/x^* \approx 1.76 > 1\): it moves away from \(x^*\) (diverges). For the average, \(g'(x^*) = \tfrac12(1 - e^{-x^*}) \approx 0.216\): converges linearly and much faster than Example 5 (about 0.66 digits per step instead of 0.25). Choosing \(g\) well is the whole game.

  3. When can a small residual \(|f(\hat x)|\) be misleading?
