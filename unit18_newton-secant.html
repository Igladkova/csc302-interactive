1. Newton's method (Heath §5.5.3)

Replace \(f\) near \(x_k\) by its tangent line, the degree-1 Taylor polynomial \(f(x_k) + f'(x_k)(x - x_k)\), and take its zero as the next iterate: \[ x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)} . \]

  • As a fixed-point iteration: \(g(x) = x - f(x)/f'(x)\) has \(g'(x^*) = f(x^*)f''(x^*)/f'(x^*)^2 = 0\) at a simple root. So convergence is quadratic (meeting 17, §5): by Taylor's theorem \(e_{k+1} \approx \dfrac{f''(x^*)}{2f'(x^*)}\,e_k^2\), and the number of correct digits roughly doubles each step.
  • Multiple roots: at a root of multiplicity \(m\), \(g'(x^*) = 1 - 1/m\), so convergence is only linear with \(C = 1 - 1/m\) (\(\tfrac12\) for a double root). If \(m\) is known, \(x_{k+1} = x_k - m\,f(x_k)/f'(x_k)\) restores quadratic convergence.
  • Only local: quadratic convergence needs \(x_0\) close to \(x^*\). Far away, Newton can overshoot, jump to another root, cycle, or diverge, and it fails when \(f'(x_k) \approx 0\).
  • Cost: each step needs \(f(x_k)\) and \(f'(x_k)\).

Examples

Example 1. Compute \(\sqrt[3]{2}\) by Newton's method on \(f(x) = x^3 - 2\) from \(x_0 = 1\). Check the quadratic error ratio.

Answer

\(x_{k+1} = x_k - \dfrac{x_k^3 - 2}{3x_k^2}\): 1, 1.3333333, 1.2638889, 1.2599335, 1.2599211. Errors 0.26, 0.0734, 0.00397, \(1.24\times10^{-5}\), \(1.23\times10^{-10}\). The ratios \(e_{k+1}/e_k^2\) are 1.09, 0.74, 0.79, approaching \(f''(x^*)/(2f'(x^*)) = 1/x^* = 0.794\).

Example 2. \(f(x) = (x - 2)^2(x + 1)\) has a double root at 2. Run Newton from \(x_0 = 3\), then the modified method with \(m = 2\).

Answer

Newton: 3, 2.5556, 2.2979, 2.1554, 2.0796, 2.0403. The error ratios 0.56, 0.54, 0.52, 0.51, 0.51 approach \(1 - \tfrac12 = \tfrac12\): linear, one bit per step. Modified (\(x - 2f/f'\)): 3, 2.1111, 2.0019, 2.0000006, quadratic again.

Example 3. What does Newton's method do for \(f(x) = \sqrt[3]{x}\) (real cube root), whose only root is 0, from \(x_0 = 0.1\)?

Answer

\(f'(x) = \tfrac13 x^{-2/3}\), so \(x_{k+1} = x_k - 3x_k = -2x_k\): 0.1, −0.2, 0.4, −0.8, 1.6, … It diverges from every \(x_0 \ne 0\). The tangent is so steep near 0 and so flat farther out that each step overshoots. Here bisection would work.

2. The secant method (Heath §5.5.4)

Replace \(f'(x_k)\) by the slope of the line through the last two points: \[ x_{k+1} = x_k - f(x_k)\,\frac{x_k - x_{k-1}}{f(x_k) - f(x_{k-1})} . \]

  • Rate: superlinear, \(e_{k+1} \approx c\,e_k e_{k-1}\), which gives \(r^2 = r + 1\), \(r = (1 + \sqrt5)/2 \approx 1.618\), the golden ratio.
  • Cost: one new function value per step and no derivative. Per function evaluation, Newton gains a factor \(2^{1/2} \approx 1.41\) in the exponent of the error and secant \(1.618\), so secant is often faster in practice, especially when \(f'\) is expensive.
  • It needs two starting values, is also only locally convergent, and suffers from cancellation in \(f(x_k) - f(x_{k-1})\) near the root (where the step is tiny anyway).

Example

Example 4. Run the secant method on \(x^3 - 2 = 0\) from \(x_0 = 1\), \(x_1 = 2\).

Answer

\(x_2 = 2 - 6 \cdot \frac{2 - 1}{6 - (-1)} = 1.1428571\), then 1.2096774, 1.2650385, 1.2597120, 1.2599202. Errors 0.117, 0.0502, 0.00512, \(2.1\times10^{-4}\), \(8.5\times10^{-7}\). Measured orders \(\log(e_{k+1}/e_k)/\log(e_k/e_{k-1})\) of 1.4 and 1.72 settle toward 1.618. It takes one more step than Newton, but each step costs one function value instead of two.

3. Interpolation methods (Heath §5.5.5–5.5.6)

  • Inverse quadratic interpolation (IQI): fit \(x\) as a quadratic function of \(y\) through the last three points \((f(x_i), x_i)\) and evaluate it at \(y = 0\). This avoids the problem of a parabola in \(x\) with no real zero. Rate \(r \approx 1.839\), one new function value per step.
  • Linear fractional interpolation: fit \(\phi(x) = (x - u)/(vx - w)\) through three points and take its zero \(u\). Its vertical and horizontal asymptotes suit functions with poles or flat tails, where tangent and secant lines are thrown far away. Rate \(r \approx 1.839\).

Example

Example 5. One IQI step for \(x^3 - 2 = 0\) from \(x = 1, 1.5, 2\).

Answer

The data are \((y, x) = (-1, 1), (1.375, 1.5), (6, 2)\). The Lagrange interpolant in \(y\), evaluated at \(y = 0\), gives \(x \approx 1.2306\) (error 0.029), already better than the best of the three starting points.

4. Safeguarded methods (Heath §5.5.7)

Fast methods (Newton, secant, IQI) are unsafe far from the root; bisection is safe but slow. Hybrid methods keep a bracket \([a, b]\) with a sign change. They try a fast step, accept it only if it stays inside the bracket and makes enough progress, and otherwise fall back to a bisection step. The Dekker–Brent method (combining bisection, secant and IQI, with no derivatives) is the standard: MATLAB's fzero, SciPy's scipy.optimize.brentq.

Example 6. brentq(lambda x: x**3 - 2, 0, 2) returns 1.2599210498949 after 8 iterations (9 function values), within \(7\times10^{-14}\) of \(\sqrt[3]{2}\), with the guaranteed safety of the bracket. Bisection would need \(\lceil\log_2(2/(2\times10^{-12}))\rceil = 40\) steps to reach brentq's default tolerance \(2\times10^{-12}\).
