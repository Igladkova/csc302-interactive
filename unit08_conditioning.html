1. Linear systems: existence and uniqueness (Heath §2.1–2.2)

For a square \(n \times n\) matrix \(A\), the system \(A\mathbf x = \mathbf b\) has a unique solution for every \(\mathbf b\) exactly when \(A\) is nonsingular. Equivalent conditions: \(A^{-1}\) exists; \(\det A \ne 0\); \(\operatorname{rank}(A) = n\); \(A\mathbf z = \mathbf 0\) only for \(\mathbf z = \mathbf 0\). If \(A\) is singular, there is either no solution (\(\mathbf b\) is not in the column space of \(A\)) or infinitely many (\(\mathbf x + \mathbf z\) for every \(\mathbf z\) in the null space). Geometrically, in 2-D each equation is a line: two crossing lines, two parallel lines, or the same line twice.

In floating point the question becomes quantitative: how close to singular is \(A\), and how much do errors in the data move \(\mathbf x\)?

2. Vector and matrix norms (Heath §2.3.1–2.3.2)

\[ \|\mathbf x\|_1 = \sum_i |x_i|, \qquad \|\mathbf x\|_2 = \Bigl(\sum_i x_i^2\Bigr)^{1/2}, \qquad \|\mathbf x\|_\infty = \max_i |x_i|, \qquad \|\mathbf x\|_\infty \le \|\mathbf x\|_2 \le \|\mathbf x\|_1 . \] The induced matrix norm \(\|A\| = \max_{\mathbf x \ne 0} \|A\mathbf x\|/\|\mathbf x\|\) is the largest stretching factor of \(A\). It satisfies \(\|A\mathbf x\| \le \|A\|\,\|\mathbf x\|\) and \(\|AB\| \le \|A\|\,\|B\|\), and:

  • \(\|A\|_1\) = maximum absolute column sum; \(\|A\|_\infty\) = maximum absolute row sum (both easy by hand);
  • \(\|A\|_2 = \sigma_{\max}(A)\), the largest singular value: the longest semi-axis of the ellipse \(\{A\mathbf x : \|\mathbf x\|_2 = 1\}\) (meeting 14).

Examples

Example 1. Compute the three norms of \(\mathbf x = (2, -3, 6)\).

Answer

\(\|\mathbf x\|_1 = 2 + 3 + 6 = 11\), \(\|\mathbf x\|_2 = \sqrt{4 + 9 + 36} = 7\), \(\|\mathbf x\|_\infty = 6\). As always, \(6 \le 7 \le 11\).

Example 2. For \(A = \begin{bmatrix} 1 & -3 \\ 2 & 5 \end{bmatrix}\), compute \(\|A\|_1\), \(\|A\|_\infty\), \(A^{-1}\), \(\operatorname{cond}_1(A)\) and \(\operatorname{cond}_\infty(A)\).

Answer

Column sums \(3, 8\): \(\|A\|_1 = 8\). Row sums \(4, 7\): \(\|A\|_\infty = 7\). \(\det A = 11\), so \(A^{-1} = \tfrac{1}{11}\begin{bmatrix} 5 & 3 \\ -2 & 1 \end{bmatrix}\), with \(\|A^{-1}\|_1 = 7/11\) and \(\|A^{-1}\|_\infty = 8/11\). Both condition numbers equal \(56/11 = 5.09\): a well-conditioned matrix. (For comparison, \(\operatorname{cond}_2(A) = 3.24\); condition numbers in different norms differ by modest factors.)

3. The condition number and error bounds (Heath §2.3.3–2.3.4)

\[ \operatorname{cond}(A) = \|A\|\,\|A^{-1}\| \ \ge 1, \qquad \operatorname{cond}(A) = \infty \text{ for singular } A. \] It is the ratio of the largest to the smallest stretching by \(A\), and it bounds how relative errors in the data are amplified: \[ \frac{\|\Delta\mathbf x\|}{\|\mathbf x\|} \le \operatorname{cond}(A)\,\frac{\|\Delta\mathbf b\|}{\|\mathbf b\|}, \qquad \frac{\|\Delta\mathbf x\|}{\|\hat{\mathbf x}\|} \le \operatorname{cond}(A)\,\frac{\|E\|}{\|A\|} \ \text{ for } (A + E)\hat{\mathbf x} = \mathbf b . \] Rule of thumb: a stable algorithm in floating point gives \(\|\hat{\mathbf x} - \mathbf x\|/\|\mathbf x\| \lesssim \operatorname{cond}(A)\,\epsilon_{\text{mach}}\), so the solution loses about \(\log_{10}\operatorname{cond}(A)\) decimal digits. Facts to remember:

  • \(\operatorname{cond}(I) = 1\); \(\operatorname{cond}(cA) = \operatorname{cond}(A)\) for any scalar \(c \ne 0\).
  • The determinant does not measure near-singularity: \(\det(0.1 I_{50}) = 10^{-50}\), yet \(\operatorname{cond} = 1\).
  • Computing \(\|A^{-1}\|\) exactly costs more than solving the system, so libraries estimate it (numpy.linalg.cond computes it; LAPACK's condition estimators are cheap).

Example

Example 3. \(A = \begin{bmatrix} 7 & 10 \\ 5 & 7 \end{bmatrix}\), \(\mathbf b = (17, 12)\), so \(\mathbf x = (1, 1)\). Compute \(\operatorname{cond}_\infty(A)\). Then change \(\mathbf b\) to \((17.01, 11.99)\) and compare the relative changes in \(\mathbf b\) and \(\mathbf x\).

Answer

\(\det A = -1\), \(A^{-1} = \begin{bmatrix} -7 & 10 \\ 5 & -7 \end{bmatrix}\); \(\|A\|_\infty = \|A^{-1}\|_\infty = 17\), so \(\operatorname{cond}_\infty(A) = 289\). \(\Delta\mathbf x = A^{-1}(0.01, -0.01) = (-0.17, 0.12)\). Relative change in \(\mathbf b\): \(0.01/17 = 5.9\times10^{-4}\); in \(\mathbf x\): \(0.17/1 = 0.17\). The amplification is exactly 289: this \(\Delta\mathbf b\) is the worst case, so the bound is attained. The two lines \(7x_1 + 10x_2 = 17\) and \(5x_1 + 7x_2 = 12\) are nearly parallel (figure).

4. Residual versus error (Heath §2.3.5)

The residual \(\mathbf r = \mathbf b - A\hat{\mathbf x}\) is computable; the error \(\hat{\mathbf x} - \mathbf x\) is not. They are related by \[ \frac{\|\hat{\mathbf x} - \mathbf x\|}{\|\hat{\mathbf x}\|} \le \operatorname{cond}(A)\,\frac{\|\mathbf r\|}{\|A\|\,\|\hat{\mathbf x}\|} . \] A small relative residual means a small backward error: \(\hat{\mathbf x}\) solves a nearby system exactly. Gaussian elimination with partial pivoting always produces a small residual (meeting 9). Whether the error is small depends on \(\operatorname{cond}(A)\).

Examples

Example 4. For the system of Example 3, the approximate solution \(\hat{\mathbf x} = (1.7, 0.5)\) is far from \(\mathbf x = (1, 1)\). Compute its residual.

Answer

\(A\hat{\mathbf x} = (16.9, 12.0)\), so \(\mathbf r = (0.1, 0)\). The relative residual is \(0.1/(17 \cdot 1.7) = 0.0035\), yet the error \((0.7, -0.5)\) is 70% of \(\|\mathbf x\|\). The bound allows it: \(289 \times 0.0035 = 1.0\).

Example 5. The Hilbert matrix \(H_n\), with \(h_{ij} = 1/(i + j - 1)\), is a classic ill-conditioned matrix. Solve \(H_n\mathbf x = H_n(1, \ldots, 1)^T\) with numpy.linalg.solve for \(n = 6, 10, 12\).

Answer

\(\operatorname{cond}(H_n) \approx 1.5\times10^{7}, 1.6\times10^{13}, 1.7\times10^{16}\); errors \(4\times10^{-10}\), \(4\times10^{-4}\), \(0.5\). Each loses about \(\log_{10}\operatorname{cond}\) digits of 16. The relative residuals stay near \(10^{-16}\) in every case: the solver is stable, and the problem is ill conditioned.

7. Try it, and review questions

Interactive: Conditioning (2 × 2), Vector p-norms, Matrix condition number and Error bound. MATH 246: Condition number and the Hilbert matrix. Lab 5 runs conditioning experiments.

  1. List four conditions equivalent to "\(A\) is nonsingular".
  2. Why is \(\|A\|_\infty\) the maximum row sum? Sketch the unit balls of the three vector norms in 2-D.
  3. Show that \(\operatorname{cond}(A) \ge 1\) for every nonsingular \(A\).
  4. Why is \(\det A\) a poor measure of how close \(A\) is to singular? Give an example.
  5. \(\operatorname{cond}(A) = 10^{7}\) and \(\mathbf b\) is exact. How many digits can you trust in double precision? In single precision (\(\epsilon_{\text{mach}} \approx 6\times10^{-8}\))?
  6. An approximate solution has a tiny residual. What can you conclude about its error, and what else do you need to know?
  7. For \(A = \begin{bmatrix} 3 & 1 \\ 3 & 1 + \delta \end{bmatrix}\) with \(0 < \delta < 1\), find \(\operatorname{cond}_\infty(A)\) as a function of \(\delta\). What happens as \(\delta \to 0\)?
  8. Explain the difference between an ill-conditioned problem and an unstable algorithm.
