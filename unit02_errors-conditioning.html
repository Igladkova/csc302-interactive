Meeting 2 summary: errors, conditioning and stability

Unit summary · Heath §1.2 · CSc 302 meeting 2

Interactive modules · CSc 302 Info · Calc pages · Unit summaries

Learning objectives

  • Compute absolute and relative errors, and relate relative error to the number of correct significant digits.
  • Split a total error into data error and computational error, and computational error into truncation and rounding.
  • Define forward and backward error, and compute both for a simple approximation.
  • Compute the relative condition number \(|x f'(x)/f(x)|\) of evaluating a function, and interpret it.
  • Distinguish an ill-conditioned problem from an unstable algorithm.

This page summarizes Heath §1.2.2–1.2.7, CSc 302 meeting 2. It builds on the approximations of meeting 1. Floating-point arithmetic, the main source of rounding error, follows in meeting 3. Lab 2 practises it.

1. Absolute and relative error (Heath §1.2.2)

For an approximation \(\hat y\) of \(y\): \[ \text{absolute error} = \hat y - y, \qquad \text{relative error} = \frac{\hat y - y}{y} \quad (y \ne 0). \] A relative error of about \(10^{-p}\) means about \(p\) correct significant decimal digits. Relative error is usually the meaningful one: an error of 1 meter is negligible in the distance to the Moon and fatal in a surgical robot. The true \(y\) is unknown in practice, so errors are estimated or bounded, never computed exactly.

Example

Example 1. The value \(2.718\) is used for \(e = 2.718281828\ldots\). Find the absolute and relative errors, and the number of correct digits.

Answer

Absolute error \(2.718 - e = -2.82\times10^{-4}\); relative error \(-1.04\times10^{-4}\): about 4 correct significant digits, which matches the four digits written.

2. Data error, computational error, truncation and rounding (Heath §1.2.3–1.2.4)

To compute \(f(x)\) we actually evaluate an approximate function \(\hat f\) at approximate data \(\hat x\): \[ \hat f(\hat x) - f(x) = \underbrace{[\hat f(\hat x) - f(\hat x)]}_{\text{computational error}} + \underbrace{[f(\hat x) - f(x)]}_{\text{propagated data error}} . \] The algorithm affects only the first term. Computational error is truncation error (from the mathematics: \(\hat f\) is a Taylor polynomial, a finite sum, a finite \(h\)) plus rounding error (from finite-precision arithmetic). In a difference quotient \((f(x + h) - f(x))/h\) the two pull in opposite directions: truncation shrinks with \(h\), rounding grows like \(\epsilon_{\text{mach}}/h\) (meetings 5 and 28).

Example

Example 2. We want \(e^1\), but the measured input is \(\hat x = 1.01\), and we evaluate \(T_3(x) = 1 + x + x^2/2 + x^3/6\) instead of \(e^x\). Split the total error.

Answer

Computational (truncation) error \(T_3(1.01) - e^{1.01} = -0.0538\); propagated data error \(e^{1.01} - e = +0.0273\); total \(T_3(1.01) - e = -0.0265\). The two errors have opposite signs and partly cancel, which is luck, not a method. Reducing only one of them could make the total worse.

3. Forward and backward error (Heath §1.2.5)

For \(\hat y \approx y = f(x)\): the forward error is \(\Delta y = \hat y - y\). The backward error is \(\Delta x = \hat x - x\), where \(\hat x\) is the input for which \(\hat y\) is exact, \(f(\hat x) = \hat y\). An answer with small backward error is the exact answer to a slightly different problem. If the input data are only known to that accuracy anyway, the answer is as good as the data deserve. An algorithm is backward stable if its backward error is always small.

Example

Example 3. \(\hat y = 2.25\) is used for \(y = \sqrt5 = 2.236068\). Find the forward and backward errors, absolute and relative.

Answer

Forward: \(2.25 - 2.236068 = 0.0139\), relative \(0.0062\). Backward: \(2.25 = \sqrt{5.0625}\), so \(\Delta x = 0.0625\), relative \(0.0125\). The relative forward error is half the relative backward error; that factor \(\tfrac12\) is the condition number of \(\sqrt x\) (next section).

4. Conditioning and stability (Heath §1.2.6–1.2.7)

A problem is ill conditioned if small relative changes in the input cause large relative changes in the output. The condition number is \[ \operatorname{cond} = \frac{|\Delta y/y|}{|\Delta x/x|} \approx \left|\frac{x f'(x)}{f(x)}\right| \quad \text{for evaluating } y = f(x), \qquad |\text{relative forward error}| \lesssim \operatorname{cond} \times |\text{relative backward error}| . \] Conditioning is a property of the problem; no algorithm and no extra precision can change it. Losing about \(\log_{10}\operatorname{cond}\) digits is unavoidable. Stability is a property of the algorithm: a stable algorithm adds no more error than the data already carry. Accuracy then requires both: stable algorithm + well-conditioned problem = accurate answer.

Examples

Example 4. Find the condition number of evaluating \(\cos x\), and evaluate it at \(x = 1\), \(1.5\) and \(1.57\). Check at \(1.57\) by changing \(x\) to \(1.5701\).

Answer

\(\operatorname{cond} = |x(-\sin x)/\cos x| = |x\tan x|\): 1.56, 21.2 and 1972. At 1.57: the relative change of \(x\) is \(10^{-4}/1.57 = 6.4\times10^{-5}\). \(\cos\) goes from \(7.963\times10^{-4}\) to \(6.963\times10^{-4}\), a relative change of \(-0.126\): about 1970 times larger. Near a zero of \(f\) the relative condition number blows up (figure).

Example 5. \(I_n = \int_0^1 x^ne^{x-1}\,dx\) satisfies \(I_0 = 1 - e^{-1}\) and, by integration by parts, \(I_n = 1 - nI_{n-1}\). Compute \(I_{20}\) by this recurrence in double precision.

Answer

The recurrence gives \(I_{20} = -30.19\), although \(0 < I_{20} < 1/21\) (the true value is \(0.04554\)). The rounding error of about \(10^{-17}\) in \(I_0\) is multiplied by \(n\) at each step, so by \(20! \approx 2.4\times10^{18}\) in all: the algorithm is unstable. Run backwards instead, \(I_{n-1} = (1 - I_n)/n\), starting from the crude guess \(I_{30} = 0\): errors are divided by \(n\) at each step, and \(I_{20}\) comes out correct to 15 digits. Same problem, different algorithm.

7. Try it, and review questions

Interactive: Rounding vs truncation error and Selectable-precision calculator. Lab 2 draws the V-shaped total error of a difference quotient.

  1. The approximation 355/113 is used for \(\pi\). How many digits are correct?
  2. Give an example of data error, truncation error and rounding error in the same computation.
  3. \(\hat y = 0.5\) approximates \(\sin 0.6\). Find the forward and backward errors.
  4. Find the condition number of \(f(x) = x - 1\). Where is it ill conditioned, and what does that have to do with cancellation?
  5. Find the condition number of \(e^x\) at \(x = -15\). Is evaluating \(e^{-15}\) hard? Is summing its Taylor series a good algorithm?
  6. True or false: a problem with condition number \(10^{8}\) can be solved accurately in double precision by a stable algorithm if we only need 6 digits.
  7. Why does the forward recurrence of Example 5 fail while the backward one succeeds?
  8. Explain the difference between an ill-conditioned problem and an unstable algorithm, with one example of each.
