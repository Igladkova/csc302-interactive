1. The interpolation problem (Heath §7.1–7.2)

Given data \((t_i, y_i)\), \(i = 1, \ldots, n\), with distinct \(t_i\), find a function \(f\) with \(f(t_i) = y_i\). Choose basis functions \(\phi_1, \ldots, \phi_n\) and write \(f(t) = \sum_j x_j\phi_j(t)\). The conditions \(f(t_i) = y_i\) form the square linear system \[ A\mathbf x = \mathbf y, \qquad a_{ij} = \phi_j(t_i). \]

  • The interpolant exists and is unique when \(A\) is nonsingular. For polynomials of degree \(< n\) through \(n\) distinct points this always holds: the interpolating polynomial is unique, whatever basis we write it in.
  • The basis affects the cost of computing the coefficients and evaluating the interpolant, and the conditioning of \(A\) (how rounding errors affect the coefficients).
  • Interpolation matches the data exactly. Noisy data call for least squares (meeting 11) instead.

2. Three bases for the same polynomial (Heath §7.3.1–7.3.3)

BasisInterpolantMatrix \(A\)Cost
Monomial \(1, t, \ldots, t^{n-1}\)\(p(t) = x_1 + x_2 t + \cdots + x_n t^{n-1}\); evaluate by Horner's methodVandermonde, full and ill-conditioned as \(n\) grows (better after shifting and scaling \(t\) to \([-1, 1]\))\(O(n^3)\) to solve
Lagrange \(\ell_j(t) = \prod_{k\ne j} \frac{t - t_k}{t_j - t_k}\)\(p(t) = \sum_j y_j\,\ell_j(t)\): the coefficients are the dataidentity (\(\ell_j(t_i) = \delta_{ij}\))\(O(n^2)\) to set up (barycentric weights); \(O(n)\) per evaluation
Newton \(\pi_j(t) = \prod_{k<j}(t - t_k)\)\(p(t) = x_1 + x_2(t - t_1) + x_3(t - t_1)(t - t_2) + \cdots\)lower triangular\(O(n^2)\) by divided differences; easy to add points

Divided differences: \(f[t_i] = y_i\) and \(f[t_i, \ldots, t_{i+k}] = \dfrac{f[t_{i+1}, \ldots, t_{i+k}] - f[t_i, \ldots, t_{i+k-1}]}{t_{i+k} - t_i}\). The Newton coefficients are the top entries \(x_j = f[t_1, \ldots, t_j]\). A new point adds one new row and one new term, leaving the old terms unchanged.

Examples

Example 1. Find the quadratic through \((-1, 4)\), \((1, 0)\), \((2, 1)\) in the monomial basis, and check \(p(0)\) with the Lagrange form.

Answer

\(x_1 - x_2 + x_3 = 4\), \(x_1 + x_2 + x_3 = 0\), \(x_1 + 2x_2 + 4x_3 = 1\). The first two give \(x_2 = -2\) and \(x_1 + x_3 = 2\); then \(x_3 = 1\), \(x_1 = 1\): \(p(t) = 1 - 2t + t^2 = (t - 1)^2\). Lagrange at \(t = 0\): \(\ell_1(0) = \frac{(0-1)(0-2)}{(-1-1)(-1-2)} = \tfrac13\), \(\ell_2(0) = \frac{(0+1)(0-2)}{(1+1)(1-2)} = 1\), \(\ell_3(0) = \frac{(0+1)(0-1)}{(2+1)(2-1)} = -\tfrac13\). So \(p(0) = 4\cdot\tfrac13 + 0\cdot1 + 1\cdot(-\tfrac13) = 1\) ✓.

Example 2. Build the divided-difference table for the same data, then add the point \((3, 8)\).

Answer

First differences: \(f[-1, 1] = \frac{0 - 4}{2} = -2\), \(f[1, 2] = 1\); second: \(f[-1, 1, 2] = \frac{1 - (-2)}{3} = 1\). So \(p_2(t) = 4 - 2(t + 1) + (t + 1)(t - 1)\), the same \((t - 1)^2\). Adding \((3, 8)\): \(f[2, 3] = 7\), \(f[1, 2, 3] = 3\), \(f[-1, 1, 2, 3] = \frac{3 - 1}{4} = 0.5\). So \(p_3(t) = p_2(t) + 0.5\,(t + 1)(t - 1)(t - 2)\). Only one new term; it vanishes at the old nodes, so they stay interpolated. Check \(p_3(3) = 4 + 0.5\cdot 8 = 8\) ✓.

3. Conditioning of the monomial basis (Heath §7.3.1)

The columns \(t^j\) of the Vandermonde matrix become nearly parallel as \(j\) grows (on \([0, 1]\), high powers all look like a function that is zero except near 1). So \(\operatorname{cond}(A)\) grows exponentially with \(n\). The interpolant itself is still fine at the nodes (a small residual), but the individual coefficients are inaccurate, and evaluating between nodes can lose digits. Shifting and scaling \(t\) to \([-1, 1]\) helps; the Lagrange and Newton forms and orthogonal (Chebyshev) bases avoid the problem.

Example 3. Condition numbers of Vandermonde matrices for \(n\) equally spaced points.

Answer

On \([0, 1]\): \(n = 5\): 690; \(n = 10\): \(1.5\times10^{7}\); \(n = 15\): \(4\times10^{11}\); \(n = 20\): \(1.2\times10^{16}\) (all digits gone). On \([-1, 1]\): 24, \(4.6\times10^3\), \(1.1\times10^6\), \(2.7\times10^8\): much better, but still exponential.

4. Interpolation error; Runge's phenomenon; Chebyshev points (Heath §7.3.4–7.3.5)

If \(f\) has \(n\) continuous derivatives and \(p\) interpolates it at \(t_1, \ldots, t_n \in [a, b]\), then for each \(t\) there is a \(\theta \in [a, b]\) with \[ f(t) - p(t) = \frac{f^{(n)}(\theta)}{n!}\,(t - t_1)(t - t_2)\cdots(t - t_n), \qquad |f - p| \le \frac{M}{n!}\max_{t\in[a,b]}\Bigl|\prod_i (t - t_i)\Bigr| . \]

  • Runge's phenomenon: for some smooth \(f\), such as \(1/(1 + 25t^2)\) on \([-1, 1]\), the high derivatives grow so fast that interpolants at equally spaced points diverge near the ends as \(n\) increases.
  • Chebyshev points \(t_i = \cos\frac{(2i - 1)\pi}{2n}\) (scaled to \([a, b]\)) cluster near the ends and make \(\max|\prod(t - t_i)|\) as small as possible (\(2^{1-n}\) on \([-1, 1]\)). The interpolants then converge for smooth \(f\), and the basis is well conditioned.
  • The other remedy is to use piecewise polynomials of low degree: splines (meeting 25).

Examples

Example 4. Bound the error of the quadratic interpolating \(e^t\) at \(0, \tfrac12, 1\), and compare with the actual error and with Chebyshev nodes.

Answer

\(M = \max_{[0,1]} |(e^t)'''| = e\), and \(\max_{[0,1]} |t(t - \tfrac12)(t - 1)| = \sqrt3/36 = 0.0481\). Bound: \(\frac{e}{6}\cdot0.0481 = 0.0218\); actual maximum error 0.0144. At the three Chebyshev points of \([0, 1]\) (0.067, 0.5, 0.933) the product's maximum drops to \(1/32 = 0.03125\): bound 0.0142, actual 0.0099.

Example 5. Maximum error on \([-1, 1]\) when interpolating Runge's function \(1/(1 + 25t^2)\) with \(n\) points.

Answer

Equally spaced: \(n = 5\): 0.44, \(n = 11\): 1.9, \(n = 21\): 60, getting worse. Chebyshev: 0.40, 0.11, 0.015, converging.

Interactive: Basis functions, Newton interpolation, Chebyshev polynomials, Error bounds, and the Interpolation Playground (Runge vs Chebyshev). Lab 12 implements Newton interpolation and measures the Runge effect.

  1. Why is the polynomial interpolating \(n\) distinct points unique among polynomials of degree \(< n\)?

  3. Why does the Vandermonde matrix become ill-conditioned, and how does shifting and scaling help?
