1. Conditioning (Heath §8.1–8.2)

A quadrature rule approximates \(I(f) = \int_a^b f(x)\,dx\) by \(Q_n(f) = \sum_{i=1}^n w_i f(x_i)\) with nodes \(x_i\) and weights \(w_i\). If the integrand is perturbed to \(\hat f\), \[ |I(\hat f) - I(f)| \le (b - a)\,\|\hat f - f\|_\infty , \] so the absolute condition number is \(b - a\). Integration averages, which damps noise, and this makes it well conditioned. The relative condition number \((b - a)\|f\|_\infty / |I(f)|\) is large only when the integral is small through cancellation. A rule whose weights are all positive keeps this good conditioning: \(\sum |w_i| = b - a\). High-order Newton–Cotes rules have negative weights and lose it.

2. Newton–Cotes rules and their errors (Heath §8.3.1)

Integrate the polynomial that interpolates \(f\) at equally spaced points: \[ M(f) = (b - a)\,f(m), \qquad T(f) = \frac{b - a}{2}\bigl(f(a) + f(b)\bigr), \qquad S(f) = \frac{b - a}{6}\bigl(f(a) + 4f(m) + f(b)\bigr), \] with \(m = (a + b)/2\). Expanding \(f\) in a Taylor series about \(m\) gives, with \(E = \frac{f''(m)}{24}(b - a)^3\), \[ I - M \approx E, \qquad I - T \approx -2E, \qquad I - S = O\bigl((b - a)^5 f^{(4)}\bigr). \] So the midpoint rule is about twice as accurate as the trapezoid rule, with the opposite sign of error. The difference \((T - M)/3\) estimates \(E\) without knowing \(f''\), and \(S = \tfrac23 M + \tfrac13 T\) cancels \(E\).

The degree of a rule is the largest \(d\) such that it integrates every polynomial of degree \(\le d\) exactly. \(M\) has degree 1, \(T\) degree 1, \(S\) degree 3: for an odd number of points, symmetry gives one extra degree.

Examples

Example 1. Apply \(M\), \(T\), \(S\) to \(\int_0^1 \frac{dx}{1 + x^2} = \frac{\pi}{4} = 0.785398\). Estimate the midpoint error from \(T - M\).

Answer

\(M = 1/1.25 = 0.8\), \(T = (1 + 0.5)/2 = 0.75\), \(S = (1 + 3.2 + 0.5)/6 = 0.783333\). Errors \(I - M = -0.0146\), \(I - T = 0.0354\), \(I - S = 0.0021\). The estimate \((T - M)/3 = -0.0167\) has the right sign and size for \(I - M\). The ratio \(0.0354/0.0146 = 2.4\) is near the predicted 2; the interval is not small, so the higher-order terms still matter.

Example 2. Find weights so that \(\int_0^1 f(x)\,dx \approx w_0 f(0) + w_1 f(\tfrac23)\) is exact for \(1\) and \(x\). What is the rule's degree?

Answer

Exact for 1: \(w_0 + w_1 = 1\); exact for \(x\): \(\tfrac23 w_1 = \tfrac12\). So \(w_1 = \tfrac34\), \(w_0 = \tfrac14\). For \(x^2\): \(\tfrac34\cdot\tfrac49 = \tfrac13\), exact! For \(x^3\): \(\tfrac34\cdot\tfrac{8}{27} = \tfrac29 \ne \tfrac14\). The degree is 2. The free node \(\tfrac23\) bought one extra degree; choosing both nodes freely gives the Gaussian rule of degree 3.

3. Gaussian quadrature (Heath §8.3.3)

With both the \(n\) nodes and the \(n\) weights free, there are \(2n\) parameters, enough to integrate all polynomials of degree \(\le 2n - 1\) exactly. On \([-1, 1]\) the nodes are the roots of the Legendre polynomial \(P_n\); the weights are all positive, so the rules are stable. The two-point rule is \(f(-1/\sqrt3) + f(1/\sqrt3)\). For \([a, b]\), substitute \(x = \frac{a + b}{2} + \frac{b - a}{2}t\): \[ \int_a^b f(x)\,dx \approx \frac{b - a}{2} \sum_{i=1}^n w_i\, f\Bigl(\frac{a + b}{2} + \frac{b - a}{2}t_i\Bigr). \] Drawbacks: the nodes of different \(n\) do not nest, so raising \(n\) wastes the old evaluations (Gauss–Kronrod rules fix this, §8.3.4), and the nodes are irrational, which makes Gaussian rules awkward for tabulated data. numpy.polynomial.legendre.leggauss(n) returns nodes and weights.

Example

Example 3. Approximate \(\int_1^3 \frac{dx}{x} = \ln 3 = 1.098612\) with Simpson's rule and with the 2- and 3-point Gauss rules.

Answer

Simpson (3 evaluations): \(\tfrac26(1 + 4\cdot\tfrac12 + \tfrac13) = 1.1111\), error \(1.2\times10^{-2}\). Gauss, 2 points: nodes \(2 \pm 1/\sqrt3 = 1.4226, 2.5774\), weights 1, sum \(0.7029 + 0.3880 = 1.0909\), error \(-7.7\times10^{-3}\). Gauss, 3 points: \(1.09804\), error \(-5.7\times10^{-4}\). With fewer function values, Gauss is more accurate.

4. Composite and adaptive quadrature (Heath §8.3.5–8.3.6)

Split \([a, b]\) into \(k\) panels of width \(h = (b - a)/k\) and apply a simple rule on each. The composite trapezoid rule is \(T_k = h\bigl(\tfrac12 f(a) + f(x_1) + \cdots + f(x_{k-1}) + \tfrac12 f(b)\bigr)\). Summing the panel errors gives a global error of \[ O(h^2) \text{ for midpoint and trapezoid}, \qquad O(h^4) \text{ for Simpson}, \qquad O(h^{2n}) \text{ for } n\text{-point Gauss}, \] provided \(f\) has enough derivatives. Any rule of degree \(\ge 0\) converges as \(h \to 0\), because the composite rule is a Riemann sum. Halving \(h\) and comparing the two results gives an error estimate for free.

Adaptive quadrature applies two rules on an interval and accepts the more accurate one if they agree to the tolerance; otherwise it bisects and recurses (Heath Algorithm 8.1). Points cluster where \(f\) changes rapidly. scipy.integrate.quad (QUADPACK, Gauss–Kronrod) is adaptive. It can be fooled: a narrow spike that no sample hits is missed entirely, and a jump wastes many subdivisions.

Examples

Example 4. The composite trapezoid rule for \(\int_0^1 \frac{dx}{1 + x^2}\) and for \(\int_0^1 \sqrt x\,dx = \tfrac23\) with \(k = 4, 8, 16, 32\). What error ratios do you see?

Answer

For \(1/(1 + x^2)\): errors \(-2.6\times10^{-3}, -6.5\times10^{-4}, -1.6\times10^{-4}, -4.1\times10^{-5}\), a ratio of 4.0 per halving: \(O(h^2)\). For \(\sqrt x\): \(-2.3\times10^{-2}, -8.5\times10^{-3}, -3.1\times10^{-3}, -1.1\times10^{-3}\), ratio about 2.8 \(\approx 2^{1.5}\): only \(O(h^{1.5})\), because \(f'\) is infinite at 0 and the error expansion fails. Remedies: substitute \(x = u^2\) (smooth integrand \(2u^2\)), or use an adaptive rule.

Example 5. \(g(x) = 1/\bigl((x - 0.3)^2 + 0.001\bigr)\) has a sharp peak at \(x = 0.3\); \(\int_0^1 g = 94.597213\) (from \(\arctan\)). Compare quad with the uniform composite trapezoid rule.

Answer

quad uses 189 evaluations in 5 subintervals, error \(2\times10^{-13}\). The composite trapezoid rule needs \(k = 1000\) panels for error \(6.5\times10^{-6}\) and \(10\,000\) for \(6.5\times10^{-8}\): most of those points lie where \(g\) is flat. 7. Try it, and review questions

Interactive: Newton–Cotes rules, Cancellation of errors (midpoint vs trapezoid), and the Integration Explorer. Lab 13 compares composite and adaptive rules.

  1. What is the absolute condition number of \(\int_a^b f\)? Why does it make integration easier than differentiation?
  2. Why is the midpoint rule about twice as accurate as the trapezoid rule? How can you estimate the error of either one without knowing \(f''\)?
  3. Define the degree of a quadrature rule. Why does Simpson's rule have degree 3, not 2?
  4. Find the weights of a rule \(w_0 f(-1) + w_1 f(0) + w_2 f(1)\) on \([-1, 1]\). Which rule is it?
  5. Why can \(n\) Gauss points integrate polynomials of degree \(2n - 1\) exactly? What is a practical drawback?
  6. Why do high-order Newton–Cotes rules become unstable?
  7. The composite trapezoid error drops by a factor of only 2.8 when \(h\) is halved. What does that tell you about \(f\)?
  8. How does adaptive quadrature decide where to put points? Describe an integrand that fools it.
