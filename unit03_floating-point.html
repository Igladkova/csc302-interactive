Learning objectives

  • Describe a floating-point system by its base \(\beta\), precision \(p\) and exponent range \([L, U]\), and count its numbers, UFL and OFL.
  • Explain rounding by chopping and to nearest, and the machine precision \(\epsilon_{\text{mach}}\) as a bound on relative rounding error.
  • State the IEEE double precision parameters, and explain subnormals, Inf and NaN.
  • Use the model \(\mathrm{fl}(x \circ y) = (x \circ y)(1 + \delta)\), \(|\delta| \le \epsilon_{\text{mach}}\), and recognize where it breaks down.
  • Detect catastrophic cancellation and avoid it by rewriting formulas; avoid overflow by scaling.

1. Floating-point systems (Heath §1.3.1–1.3.3)

A normalized floating-point number has the form \[ x = \pm\Bigl(d_0 + \frac{d_1}{\beta} + \cdots + \frac{d_{p-1}}{\beta^{p-1}}\Bigr)\beta^{E}, \qquad 0 \le d_i \le \beta - 1, \ d_0 \ne 0, \ L \le E \le U . \] Such a system contains \(2(\beta - 1)\beta^{p-1}(U - L + 1) + 1\) numbers (with zero), the underflow level \(\text{UFL} = \beta^L\) and the overflow level \(\text{OFL} = \beta^{U+1}(1 - \beta^{-p})\). The numbers are not equally spaced: the gap is constant within each power of \(\beta\) and grows by a factor \(\beta\) from one to the next (figure), so the relative spacing stays roughly constant.

IEEE double precision (Python float, NumPy float64): \(\beta = 2\), \(p = 53\), \(L = -1022\), \(U = 1023\); \(\text{UFL} \approx 2.2\times10^{-308}\), \(\text{OFL} \approx 1.8\times10^{308}\), about 16 decimal digits. Single precision: \(p = 24\), about 7 digits.

Example

Example 1. A binary system has \(p = 4\), \(L = -2\), \(U = 1\), and rounds to nearest. Count its numbers, and find UFL, OFL and \(\epsilon_{\text{mach}}\).

Answer

\(2\cdot1\cdot2^3\cdot4 + 1 = 65\) numbers. \(\text{UFL} = 2^{-2} = 0.25\); \(\text{OFL} = 2^2(1 - 2^{-4}) = 3.75\); \(\epsilon_{\text{mach}} = \tfrac12\cdot2^{1-4} = 0.0625\). Between 1 and 2 the gap is \(2^{-3} = 0.125\); between 2 and 4 it is 0.25.

2. Rounding and machine precision (Heath §1.3.4–1.3.7)

A real number \(x\) is stored as \(\mathrm{fl}(x)\): chopping drops the extra digits; rounding to nearest (the IEEE default, ties to even) picks the closest number. In either case \[ \left|\frac{\mathrm{fl}(x) - x}{x}\right| \le \epsilon_{\text{mach}}, \qquad \epsilon_{\text{mach}} = \tfrac12\beta^{1-p} \ (\text{nearest}), \quad \beta^{1-p} \ (\text{chopping}) . \] For double precision \(\epsilon_{\text{mach}} = 2^{-53} \approx 1.1\times10^{-16}\). (NumPy's np.finfo(float).eps \(= 2^{-52}\) is the gap from 1 to the next number, which is \(2\epsilon_{\text{mach}}\).) Do not confuse \(\epsilon_{\text{mach}}\), set by \(p\), with UFL, set by \(L\): \(\epsilon_{\text{mach}} \approx 10^{-16}\) while \(\text{UFL} \approx 10^{-308}\).

  • Subnormals (gradual underflow): numbers below UFL with \(d_0 = 0\) fill the gap down to about \(5\times10^{-324}\), with lower relative precision.
  • Exceptional values: inf from overflow or \(1/0\); nan from \(0/0\), \(\infty - \infty\), \(\sqrt{-1}\). NaN propagates through later arithmetic, and \(\text{NaN} \ne \text{NaN}\).

3. Floating-point arithmetic and cancellation (Heath §1.3.8–1.3.9)

IEEE arithmetic rounds the exact result: \(\mathrm{fl}(x \circ y) = (x \circ y)(1 + \delta)\) with \(|\delta| \le \epsilon_{\text{mach}}\), for \(\circ\) one of \(+, -, \times, \div\). Each single operation is accurate, but:

  • arithmetic is commutative but not associative: the order of summation matters;
  • adding a number smaller than \(\epsilon_{\text{mach}}\) times another has no effect;
  • cancellation: subtracting nearly equal numbers is exact, but it exposes the errors already in them. Leading digits cancel, and the result has few correct digits (relative condition number \(|x|/|x - y|\)). The cure is to rewrite the formula so that no such subtraction occurs.

Examples

Example 2. In double precision, evaluate \(1 + 2^{-53} == 1\), \(1 + 2^{-52} == 1\), \((10^{16} + 1) - 10^{16}\), and \((10^{16} - 10^{16}) + 1\).

Answer

True (the exact sum is halfway between 1 and \(1 + 2^{-52}\), and ties go to even); False; 0.0 (the spacing near \(10^{16}\) is 2, so \(10^{16} + 1\) rounds back to \(10^{16}\)); 1.0. Same numbers, different order, different answer.

Example 3. Evaluate \(\sqrt{x + 1} - \sqrt x\) for \(x = 10^8, 10^{12}, 10^{15}\), directly and as \(1/(\sqrt{x + 1} + \sqrt x)\).

Answer

The relative errors of the direct form are \(1.4\times10^{-8}\), \(7.6\times10^{-6}\) and \(0.18\): about half, two-thirds, then all of the digits lost. The rewritten form (multiply and divide by the conjugate) has no subtraction and is correct to about \(10^{-16}\) for every \(x\). Both formulas are equal in exact arithmetic (figure).

Example 4. Compute \(\sqrt{a^2 + b^2}\) for \(a = 3\times10^{200}\), \(b = 4\times10^{200}\).

Answer

\(a^2 = 9\times10^{400}\) overflows, so the direct formula returns inf, although the answer \(5\times10^{200}\) is representable. Scale first: with \(m = \max(|a|, |b|)\), compute \(m\sqrt{(a/m)^2 + (b/m)^2}\). That is what math.hypot and numpy.hypot do, returning \(5\times10^{200}\).

4. Mathematical software (Heath §1.4)

Use well-tested libraries rather than your own code for standard tasks. Python's scientific stack is NumPy, SciPy and Matplotlib, built on LAPACK and BLAS (meeting 10) and on QUADPACK, MINPACK and others. Library functions such as numpy.log1p, numpy.expm1, numpy.hypot and math.fsum exist precisely to avoid cancellation, overflow and summation error. Higher precision is available when needed (mpmath, decimal), at a large cost in speed.
