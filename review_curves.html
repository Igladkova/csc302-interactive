1. Parametric curves in the plane (Stewart §10.1)

A pair of parametric equations \(x = f(t)\), \(y = g(t)\), \(\alpha \le t \le \beta\), traces a curve: each \(t\) gives a point, and as \(t\) increases the point moves along the curve in a definite direction (orientation). The same set of points can be traced by different parametrizations, at different speeds or in opposite directions.

  • Eliminating the parameter: solve one equation for \(t\), or use an identity such as \(\cos^2 t + \sin^2 t = 1\), to get an equation in \(x\) and \(y\). This shows the shape but loses the direction and the speed.
  • Standard ones: \((a\cos t, a\sin t)\) is a circle of radius \(a\), counterclockwise; \((a\cos t, b\sin t)\) an ellipse; \((x_0 + v_1 t, y_0 + v_2 t)\) a line through \((x_0, y_0)\) with direction \(\langle v_1, v_2\rangle\); and \(y = F(x)\) can always be written \(x = t\), \(y = F(t)\).

Examples

Example 1. Identify the curve \(x = 2\cos t\), \(y = 3\sin t\), \(0 \le t \le 2\pi\), and its direction.

Answer

\((x/2)^2 + (y/3)^2 = \cos^2 t + \sin^2 t = 1\): the ellipse \(\frac{x^2}{4} + \frac{y^2}{9} = 1\). At \(t = 0\) the point is \((2, 0)\) and at \(t = \pi/2\) it is \((0, 3)\): counterclockwise, once around.

Example 2. Eliminate the parameter: \(x = t^2 - 1\), \(y = t + 1\).

Answer

\(t = y - 1\), so \(x = (y - 1)^2 - 1\): a parabola opening to the right with vertex \((-1, 1)\), traced upward as \(t\) increases.

2. Vector functions and space curves (Stewart §13.1–13.2)

A vector function \(\mathbf r(t) = \langle f(t), g(t), h(t)\rangle\) assigns a vector to each \(t\). Its tip traces a space curve. Limits, continuity, derivatives and integrals are taken component by component (Stewart, Theorem 13.2.2): \[ \mathbf r'(t) = \langle f'(t), g'(t), h'(t)\rangle, \qquad \int_a^b \mathbf r(t)\,dt = \Bigl\langle \int_a^b f, \int_a^b g, \int_a^b h \Bigr\rangle. \]

  • \(\mathbf r'(t)\) is the tangent vector (velocity, if \(t\) is time); \(\mathbf T(t) = \mathbf r'(t)/|\mathbf r'(t)|\) is the unit tangent vector, defined where \(\mathbf r' \ne \mathbf 0\).
  • The tangent line at \(\mathbf r(t_0)\) is \(\boldsymbol\ell(s) = \mathbf r(t_0) + s\,\mathbf r'(t_0)\).
  • The usual rules hold: sums, scalar multiples, dot and cross products, and the chain rule (Stewart, Theorem 13.2.3).
  • Example: the helix \(\langle \cos t, \sin t, t\rangle\) winds around the cylinder \(x^2 + y^2 = 1\).

Arc length (Stewart §13.3)

For a curve traversed once for \(a \le t \le b\), with \(\mathbf r'\) continuous, \[ L = \int_a^b |\mathbf r'(t)|\,dt = \int_a^b \sqrt{f'(t)^2 + g'(t)^2 + h'(t)^2}\;dt , \] the integral of the speed. In the plane, drop the \(h'\) term (this is Stewart's Theorem 10.2.5). Most arc-length integrals have no closed form, which is where numerical quadrature comes in.

Examples

Example 3. For \(\mathbf r(t) = \langle t^2, e^t, \sin \pi t\rangle\), find the tangent line at \(t = 1\).

Answer

\(\mathbf r(1) = \langle 1, e, 0\rangle\) and \(\mathbf r'(t) = \langle 2t, e^t, \pi\cos\pi t\rangle\), so \(\mathbf r'(1) = \langle 2, e, -\pi\rangle\). Tangent line: \(\boldsymbol\ell(s) = \langle 1 + 2s,\ e + es,\ -\pi s\rangle\).

Example 4. Evaluate \(\displaystyle\int_0^1 \Bigl\langle 2t,\ 3t^2,\ \frac{1}{1+t} \Bigr\rangle dt\).

Answer

Component by component: \(\langle 1, 1, \ln 2\rangle\).

Example 5. Find the length of \(\mathbf r(t) = \langle 2t, t^2, \ln t\rangle\) for \(1 \le t \le e\).

Answer

\(\mathbf r'(t) = \langle 2, 2t, 1/t\rangle\), \(|\mathbf r'(t)|^2 = 4 + 4t^2 + 1/t^2 = (2t + 1/t)^2\). So \(L = \int_1^e (2t + 1/t)\,dt = (e^2 - 1) + 1 = e^2 \approx 7.389\). (The perfect square is a lucky case; usually the integral is done numerically.)

3. Why CSc 302 needs this

  • Spline curves: interpolating \(x(t)\) and \(y(t)\) separately through data points gives a smooth curve through the points in order. This is how fonts, animation paths and robot trajectories are drawn (meeting 25, Lab 12).
  • Arc length of a measured or interpolated curve, for example a GPS track, is a quadrature problem (meetings 25–26).
  • Tangent vectors come from differentiating the interpolant, and differentiating data amplifies noise (meeting 28).

Review questions

  1. How do the parametrizations \((\cos t, \sin t)\) and \((\cos 2t, \sin 2t)\), \(0 \le t \le 2\pi\), differ? What about \((\sin t, \cos t)\)?
  2. Eliminate the parameter in \(x = e^t\), \(y = e^{2t}\). Which part of the resulting curve is traced?
  3. How do you differentiate and integrate a vector function?
  4. What do \(\mathbf r'(t)\) and \(\mathbf T(t)\) represent geometrically? When is \(\mathbf T\) undefined?
  5. Write the tangent line to a space curve at a point.
  6. Why is \(\mathbf r'(t) \perp \mathbf r(t)\) when \(|\mathbf r(t)|\) is constant (Stewart, Theorem 13.2.4)?
  7. Write the arc length of a curve as an integral. Find the length of the helix \(\langle \cos t, \sin t, t\rangle\), \(0 \le t \le 2\pi\).
  8. Why does arc length not depend on the parametrization (as long as the curve is traced once)?
