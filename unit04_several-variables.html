1. Why several variables in a numerical course

Almost every problem in CSc 302 has many unknowns: a linear system has \(n\) of them, a least squares fit minimizes a function of its coefficients, Newton's method for systems (meeting 19) and every optimization method (meetings 20–23) work with \(f(x_1, \ldots, x_n)\). The tools are the multivariable versions of the one-variable ones: partial derivatives and the gradient (slopes), the Jacobian (linearization), the Hessian (curvature). Contour plots are the main way to see what an algorithm is doing (figure).

2. Graphs, level curves and contour plots (Stewart §14.1)

A function \(f(x, y)\) assigns a number to each point of its domain \(D \subset \mathbb R^2\). Its graph is the surface \(z = f(x, y)\). Its level curves are \(f(x, y) = k\), the horizontal slices of the surface projected onto the plane, and a contour plot draws many of them. Where the level curves (for equally spaced \(k\)) crowd together, the surface is steep. Level curves of different heights never cross. For three variables, \(f(x, y, z) = k\) defines level surfaces.

In Python:

x = np.linspace(-2, 2, 201); y = np.linspace(-2, 2, 201)
X, Y = np.meshgrid(x, y)              # grids of x and y values
Z = np.exp(-(X**2 + 2*Y**2))           # evaluate f on the whole grid at once
plt.contour(X, Y, Z, levels=10); plt.axis("equal")
ax = plt.figure().add_subplot(projection="3d"); ax.plot_surface(X, Y, Z)

Example

Example 1. Describe the level curves of \(f(x, y) = e^{-(x^2 + 2y^2)}\) and of \(g(x, y) = xy\).

Answer

\(f = k\) means \(x^2 + 2y^2 = -\ln k\): for \(0 < k < 1\), ellipses centered at the origin with semi-axes \(\sqrt c\) in \(x\) and \(\sqrt{c/2}\) in \(y\), where \(c = -\ln k\); a single point for \(k = 1\) (the maximum); empty for \(k > 1\) or \(k \le 0\). The surface is a bump. \(g = k\) gives hyperbolas \(y = k/x\), in the first and third quadrants for \(k > 0\), the second and fourth for \(k < 0\), and the two axes for \(k = 0\): a saddle.

3. Limits and continuity (Stewart §14.2)

\(\lim_{(x,y)\to(a,b)} f(x, y) = L\) means \(f(x, y)\) is close to \(L\) for all \((x, y)\) close enough to \((a, b)\), approached from any direction along any path. So:

  • if two paths give different limits, the limit does not exist;
  • agreement along every straight line is not enough; a curved path may disagree;
  • to prove a limit exists, bound \(|f - L|\) by something that goes to 0, for example in polar coordinates \(x = r\cos\theta\), \(y = r\sin\theta\), with a bound independent of \(\theta\).

\(f\) is continuous at \((a, b)\) if the limit equals \(f(a, b)\). Polynomials are continuous everywhere; rational functions wherever the denominator is nonzero; sums, products and compositions of continuous functions are continuous. Most theorems used later (Clairaut, the chain rule, the second-derivative test) assume continuity.

Examples

Example 2. Does \(\displaystyle\lim_{(x,y)\to(0,0)} \frac{x^2y}{x^4 + y^2}\) exist? Evaluate along \(y = mx\) and along \(y = x^2\).

Answer

Along \(y = mx\): \(\frac{mx^3}{x^4 + m^2x^2} = \frac{mx}{x^2 + m^2} \to 0\) for every \(m\), and along \(x = 0\) the value is 0 as well. Along \(y = x^2\): \(\frac{x^4}{2x^4} = \tfrac12\); along \(y = -x^2\): \(-\tfrac12\). The limit does not exist. Numerically, at \(x = 10^{-6}\) the values along \(y = x\), \(y = 2x\), \(y = x^2\) are \(10^{-6}\), \(5\times10^{-7}\) and \(0.5\). A table along straight lines alone would have suggested the limit 0 (figure).

Example 3. Show that \(\displaystyle\lim_{(x,y)\to(0,0)} \frac{x^3 + y^3}{x^2 + y^2} = 0\).

Answer

In polar coordinates the function is \(r(\cos^3\theta + \sin^3\theta)\), and \(|\cos^3\theta + \sin^3\theta| \le 2\). So \(|f| \le 2r \to 0\) as \(r \to 0\), whatever the path.

Example 4. \(h(x, y) = \sin(x^2 + y^2)/(x^2 + y^2)\) tends to 1 at the origin (with \(u = x^2 + y^2\), \(\sin u/u \to 1\)). Evaluate it in double precision at \(x = y = 10^{-8}\), \(10^{-160}\) and \(10^{-200}\).

Answer

\(1.0\) and \(1.0\) (at \(10^{-160}\), \(u = 2\times10^{-320}\) is a subnormal number), then nan: at \(10^{-200}\), \(x^2 = 10^{-400}\) underflows to 0, so the code computes \(0/0\). The mathematics has a removable singularity; the program needs a special case, e.g. return \(1 - u^2/6\) when \(u\) is tiny (Taylor, meeting 1).

6. Try it, and review questions

Interactive: Surfaces and level curves. Lab 3 draws 3-D plots and contour maps.

  1. Sketch the level curves of \(f(x, y) = y - \sin x\) for \(k = -1, 0, 1\).
  2. A contour plot has level curves crowded near one point and widely spaced near another. What does that say about the surface?
  3. Why can two level curves of the same function never cross?
  4. Show that \(\frac{xy}{x^2 + y^2}\) has no limit at the origin. Then show that \(\frac{x^2y^2}{x^2 + y^2}\) does.
  5. True or false: if a function tends to the same value along every line through the origin, it has a limit there. Give a counterexample.
  6. Where is \(f(x, y) = \ln(x + y - 1)\) continuous? Sketch the domain.
  7. Why does evaluating \(f\) on a fine grid near a point never prove that a limit exists?
  8. Write Python code that draws 15 contour lines of \(f(x, y) = x^2 - y^2\) on \([-2, 2]^2\).
