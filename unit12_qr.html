1. Orthogonal transformations and QR (Heath §3.4.3–3.4.5)

A square matrix \(Q\) is orthogonal if \(Q^TQ = I\). Then \(\|Q\mathbf v\|_2 = \|\mathbf v\|_2\) for every \(\mathbf v\), so multiplying the residual by \(Q^T\) does not change the least squares problem. If \[ A = Q\begin{bmatrix} R \\ O \end{bmatrix} \ \ (\text{full QR}), \qquad A = Q_1R \ \ (\text{reduced QR, } Q_1 \in \mathbb R^{m\times n}), \qquad R \text{ upper triangular } n\times n, \] then \(\|\mathbf b - A\mathbf x\|_2^2 = \|\mathbf c_1 - R\mathbf x\|_2^2 + \|\mathbf c_2\|_2^2\) with \(Q^T\mathbf b = (\mathbf c_1, \mathbf c_2)\). So the solution is \[ R\mathbf x = Q_1^T\mathbf b \quad (\text{back substitution}), \qquad \|\mathbf r\|_2 = \|\mathbf c_2\|_2 . \] Since \(\operatorname{cond}(R) = \operatorname{cond}(A)\), no squaring of the condition number occurs. The factorization is computed by orthogonal transformations that zero out entries below the diagonal, column by column.

2. Householder reflections (Heath §3.5.1)

\(H = I - 2\dfrac{\mathbf v\mathbf v^T}{\mathbf v^T\mathbf v}\) reflects across the hyperplane perpendicular to \(\mathbf v\); it is symmetric and orthogonal (\(H^{-1} = H\)). To map \(\mathbf a\) onto a multiple of \(\mathbf e_1\), take \[ \mathbf v = \mathbf a - \alpha\mathbf e_1, \qquad \alpha = -\operatorname{sign}(a_1)\,\|\mathbf a\|_2, \qquad H\mathbf a = \alpha\mathbf e_1 . \] The sign choice avoids cancellation in \(v_1 = a_1 - \alpha\). In practice \(H\) is never formed: \(H\mathbf u = \mathbf u - 2\frac{\mathbf v^T\mathbf u}{\mathbf v^T\mathbf v}\mathbf v\) costs \(O(m)\). Householder QR applies \(n\) reflections, one per column, at a cost of about \(mn^2 - n^3/3\) multiplications. This is the standard method (LAPACK geqrf, numpy.linalg.qr).

Example

Example 1. Find the Householder vector that maps \(\mathbf a = (1, 2, 2)\) to a multiple of \(\mathbf e_1\), and the matrix \(H\).

Answer

\(\|\mathbf a\|_2 = 3\) and \(a_1 > 0\), so \(\alpha = -3\) and \(\mathbf v = (1 + 3, 2, 2) = (4, 2, 2)\), \(\mathbf v^T\mathbf v = 24\), \(\mathbf v^T\mathbf a = 12\). \(H\mathbf a = \mathbf a - 2\cdot\tfrac{12}{24}\mathbf v = (1, 2, 2) - (4, 2, 2) = (-3, 0, 0)\). Explicitly \(H = \tfrac13\begin{bmatrix} -1 & -2 & -2 \\ -2 & 2 & -1 \\ -2 & -1 & 2 \end{bmatrix}\), symmetric with orthonormal columns.

3. Givens rotations (Heath §3.5.2)

A plane rotation \(G = \begin{bmatrix} c & s \\ -s & c \end{bmatrix}\), with \(c = a_1/r\), \(s = a_2/r\), \(r = \sqrt{a_1^2 + a_2^2}\), maps \((a_1, a_2)\) to \((r, 0)\). Embedded in rows \(i, j\) of an identity matrix, it zeros one entry at a time. That makes it ideal for sparse matrices, or for updating a factorization when rows are added. For a dense matrix it costs about 50% more than Householder.

Example

Example 2. Find the Givens rotation that zeros the second entry of \((8, 15)\).

Answer

\(r = \sqrt{64 + 225} = 17\), \(c = 8/17 = 0.4706\), \(s = 15/17 = 0.8824\). Check: \(G(8, 15) = (64/17 + 225/17,\ -120/17 + 120/17) = (17, 0)\).

4. Gram–Schmidt orthogonalization (Heath §3.5.3)

Orthogonalize the columns one at a time: subtract from \(\mathbf a_k\) its components along \(\mathbf q_1, \ldots, \mathbf q_{k-1}\), then normalize: \[ r_{jk} = \mathbf q_j^T\mathbf a_k \ (j < k), \qquad \mathbf w_k = \mathbf a_k - \sum_{j<k} r_{jk}\mathbf q_j, \qquad r_{kk} = \|\mathbf w_k\|_2, \qquad \mathbf q_k = \mathbf w_k/r_{kk} . \] This gives the reduced QR directly. Classical Gram–Schmidt (CGS) computes all \(r_{jk}\) from the original \(\mathbf a_k\). In floating point the computed \(\mathbf q_k\) gradually lose orthogonality, roughly like \(\operatorname{cond}(A)^2\epsilon_{\text{mach}}\). Modified Gram–Schmidt (MGS) subtracts each component from the updated vector; it is the same in exact arithmetic but loses orthogonality only like \(\operatorname{cond}(A)\,\epsilon_{\text{mach}}\). Householder QR keeps \(Q\) orthogonal to machine precision regardless of \(\operatorname{cond}(A)\) (figure).

Example

Example 3. Solve the least squares problem of the meeting 11 summary, \(A = \begin{bmatrix} 1 & 0 \\ 0 & 1 \\ 1 & 1 \end{bmatrix}\), \(\mathbf b = (1, 2, 6)\), by Gram–Schmidt QR.

Answer

\(r_{11} = \sqrt2\), \(\mathbf q_1 = (1, 0, 1)/\sqrt2\). \(r_{12} = \mathbf q_1^T\mathbf a_2 = 1/\sqrt2\); \(\mathbf w_2 = (0, 1, 1) - \tfrac12(1, 0, 1) = (-\tfrac12, 1, \tfrac12)\), \(r_{22} = \sqrt{1.5} = 1.2247\), \(\mathbf q_2 = (-1, 2, 1)/\sqrt6\). Then \(Q_1^T\mathbf b = (7/\sqrt2, 9/\sqrt6) = (4.9497, 3.6742)\). Back substitution: \(x_2 = 3.6742/1.2247 = 3\), \(x_1 = (4.9497 - 0.7071\cdot3)/1.4142 = 2\). Same answer \(\mathbf x = (2, 3)\) as the normal equations; \(\|\mathbf r\|_2^2 = \|\mathbf b\|_2^2 - \|Q_1^T\mathbf b\|_2^2 = 41 - 38 = 3\).

5. Rank deficiency, comparison and software (Heath §3.5.4, §3.7–3.8)

If the columns are (nearly) dependent, \(R\) has a (nearly) zero diagonal entry. QR with column pivoting chooses at each step the remaining column of largest norm, which reveals the numerical rank. The SVD (meeting 14) is the most reliable tool for rank-deficient problems, and gives the minimum-norm solution.

MethodCost (\(m \gg n\))AccuracyPython
Normal equations + Cholesky\(mn^2/2 + n^3/6\)\(\sim\operatorname{cond}(A)^2\epsilon_{\text{mach}}\)scipy.linalg.cho_solve on \(A^TA\)
Householder QR\(mn^2 - n^3/3\)\(\sim\operatorname{cond}(A)\,\epsilon_{\text{mach}}\) (small \(\theta\))numpy.linalg.qr, scipy.linalg.qr (pivoting)
Modified Gram–Schmidt\(mn^2\)\(R\) and \(\mathbf x\) good; \(Q\) loses orthogonality \(\sim\operatorname{cond}\cdot\epsilon\)(own code)
SVDseveral times QRmost robust; rank-deficient OKnumpy.linalg.lstsq, pinv

For \(m = 1000\), \(n = 10\): normal equations about \(5.0\times10^4\) multiplications, Householder about \(1.0\times10^5\). The extra factor of 2 buys about \(\log_{10}\operatorname{cond}(A)\) more correct digits.
