1. Conditioning of differentiation (Heath §8.6)

Two functions can be uniformly close yet have very different derivatives: \(f(x) + \delta\sin(x/\delta^2)\) differs from \(f\) by at most \(\delta\), but its derivative differs by up to \(1/\delta\). So differentiation amplifies small perturbations: it is ill conditioned, the opposite of integration (meeting 26). Consequences:

  • for a smooth function you can evaluate anywhere, finite differences work, with a carefully chosen \(h\);
  • for noisy or measured data with noise level \(\delta\), a difference quotient over spacing \(h\) has error up to about \(\delta/h\). Fit a smooth function first (least squares, meeting 11, or a smoothing spline), then differentiate the fit.

2. Finite difference formulas (Heath §8.6.1)

From \(f(x \pm h) = f(x) \pm f'(x)h + \tfrac12 f''(x)h^2 \pm \tfrac16 f'''(x)h^3 + \cdots\): \[ \frac{f(x + h) - f(x)}{h} = f'(x) + \frac{f''(x)}{2}h + \cdots, \qquad \frac{f(x + h) - f(x - h)}{2h} = f'(x) + \frac{f'''(x)}{6}h^2 + \cdots, \] \[ \frac{f(x + h) - 2f(x) + f(x - h)}{h^2} = f''(x) + \frac{f^{(4)}(x)}{12}h^2 + \cdots . \] The forward (and backward) difference is first order; the centered differences are second order. The same formulas come from differentiating the interpolating polynomial through the points (meeting 24).

Rounding. Each value of \(f\) carries a relative error of about \(\epsilon_{\text{mach}}\), and the subtraction cancels digits. So the computed forward difference has total error about \[ \frac{|f''|}{2}h + \frac{2\epsilon_{\text{mach}}|f|}{h}, \quad \text{minimized near } h \approx 2\sqrt{\epsilon_{\text{mach}}|f|/|f''|} \sim 10^{-8}, \] with best error \(\sim 10^{-8}\) (half the digits). For the centered difference the optimum is \(h \sim \epsilon_{\text{mach}}^{1/3} \approx 10^{-5}\), with best error \(\sim 10^{-11}\). Plotted on log–log axes the error is V-shaped: truncation on the right, rounding on the left (figure).

Examples

Example 1. For \(f(x) = \ln x\) at \(x = 2\) (\(f' = 0.5\), \(f'' = -0.25\)), compute the forward and centered differences for \(f'\), and the centered difference for \(f''\), with \(h = 0.1\). Compare the errors with the leading Taylor terms.

Answer

Forward: \((\ln 2.1 - \ln 2)/0.1 = 0.487902\), error \(-0.0121\); predicted \(\tfrac12 f''h = -0.0125\). Centered: \((\ln 2.1 - \ln 1.9)/0.2 = 0.500417\), error \(4.17\times10^{-4}\); predicted \(\tfrac16 f'''h^2 = \tfrac16\cdot\tfrac{2}{8}\cdot 0.01 = 4.17\times10^{-4}\). Second derivative: \(-0.250313\), error \(-3.1\times10^{-4}\) (predicted \(\tfrac{1}{12}f^{(4)}h^2 = -3.1\times10^{-4}\), since \(f^{(4)} = -6/x^4\)).

Example 2. For the same \(f\), reduce \(h\) from \(10^{-1}\) to \(10^{-15}\). Where is each formula most accurate?

Answer

The forward-difference error falls like \(h\) to \(3\times10^{-9}\) at \(h = 10^{-8}\) (predicted optimum \(5\times10^{-8}\)), then grows. The centered error falls like \(h^2\) to \(9\times10^{-12}\) at \(h = 10^{-5}\) (predicted optimum \(1.2\times10^{-5}\)). At \(h = 10^{-13}\) both are wrong by \(4\times10^{-4}\), and at \(10^{-15}\) by up to \(6\times10^{-2}\): smaller \(h\) is not always better.

3. Richardson extrapolation (Heath §8.7)

If \(F(h) = a_0 + a_1 h^p + O(h^r)\) with known \(p < r\), compute \(F\) at \(h\) and \(h/q\) and eliminate the \(h^p\) term: \[ F(0) \approx F(h/q) + \frac{F(h/q) - F(h)}{q^p - 1}, \qquad \text{error } O(h^r). \] For \(q = 2\): \(p = 1\) gives \(2F(h/2) - F(h)\); \(p = 2\) gives \(\bigl(4F(h/2) - F(h)\bigr)/3\). The difference \(F(h/2) - F(h)\) also estimates the error of \(F(h/2)\), which is how adaptive codes check themselves.

Romberg integration applies this repeatedly to the composite trapezoid rule, whose error expansion contains only even powers of \(h\): \[ T_{k,0} = T\bigl(h_0/2^k\bigr), \qquad T_{k,j} = \frac{4^j T_{k,j-1} - T_{k-1,j-1}}{4^j - 1}. \] The column \(T_{k,1}\) is Simpson's rule (\(O(h^4)\)), \(T_{k,2}\) is \(O(h^6)\), and so on. Halving \(h\) reuses all the old points.

Examples

Example 3. Extrapolate the centered differences of \(\ln x\) at 2 with \(h = 0.2\) and \(h = 0.1\).

Answer

\(F(0.2) = (\ln 2.2 - \ln 1.8)/0.4 = 0.501677\) (error \(1.7\times10^{-3}\)) and \(F(0.1) = 0.500417\) (error \(4.2\times10^{-4}\)), so \(p = 2\): \(\bigl(4(0.500417) - 0.501677\bigr)/3 = 0.4999975\), error \(-2.5\times10^{-6}\). With the same four function values this is about 170 times more accurate than \(F(0.1)\): a fourth-order formula.

Example 4. Build the Romberg table to \(T_{2,2}\) for \(\int_0^1 x e^x\,dx = 1\).

Answer

Trapezoid values with \(h = 1, \tfrac12, \tfrac14\): \(T_{0,0} = e/2 = 1.359141\), \(T_{1,0} = 1.091751\), \(T_{2,0} = 1.023064\) (errors \(0.36, 0.092, 0.023\): the \(O(h^2)\) factor of 4). First extrapolation: \(T_{1,1} = 1.002621\), \(T_{2,1} = 1.000169\). Second: \(T_{2,2} = (16 \cdot 1.000169 - 1.002621)/15 = 1.000006\), error \(6\times10^{-6}\), from only 5 function values.

4. Automatic differentiation (Heath §8.6.2)

A program computes \(f\) as a sequence of elementary operations, each with a known derivative. Forward-mode AD carries a pair (value, derivative) through every operation and applies the chain rule at each step: \[ (u, u') + (v, v') = (u + v,\ u' + v'), \quad (u, u')(v, v') = (uv,\ u'v + uv'), \quad \sin(u, u') = (\sin u,\ u'\cos u). \] There is no step size \(h\), so there is no truncation error and no cancellation: the derivative is exact up to rounding, at a cost of a small multiple of evaluating \(f\). Reverse mode (backpropagation in machine learning) computes a whole gradient \(\nabla f\) at a cost of a small multiple of one evaluation of \(f\), whatever the number of variables. Python libraries: JAX, PyTorch (torch.autograd).

Example

Example 5. Trace forward-mode AD for \(f(x) = x\sin(x^2)\) at \(x = 1\).

Answer

Start with \((x, x') = (1, 1)\). Then \(v_1 = x^2\): \((1, 2)\). \(v_2 = \sin v_1\): \((\sin 1, 2\cos 1) = (0.841471, 1.080605)\). \(v_3 = x\,v_2\): \((0.841471,\ 1\cdot 0.841471 + 1\cdot 1.080605) = (0.841471, 1.922076)\). The hand derivative \(\sin x^2 + 2x^2\cos x^2 = 1.922076\) agrees to all digits.

8. Try it, and review questions

Interactive: Finite differences, Numerical differentiation (the error-vs-\(h\) V), Richardson extrapolation and Romberg integration. Lab 14 differentiates noisy data.

  1. Give an example of two functions that are close but whose derivatives are far apart. What does it say about conditioning?
  2. Derive the centered difference formula and its leading error term.
  3. Why does the error of a finite difference grow again when \(h\) gets too small? Estimate the best \(h\) for the centered difference.
  4. Data have noise of size \(10^{-3}\) and spacing \(0.01\). How large can the error of a difference quotient be? What should you do instead?
  5. Derive the Richardson formula for \(p = 2\), \(q = 2\). What order results if the next term is \(h^4\)?
  6. Why does Romberg integration start from the trapezoid rule? What is \(T_{1,1}\)?
  7. Trace forward-mode AD for \(f(x) = e^{x}\cos x\) at \(x = 0\).
  8. Compare finite differences, symbolic differentiation and AD for computing the gradient of a function given by a long program.
