Learning objectives

  • State an optimization problem (objective, variables, constraints) and the difference between local and global minima.
  • Use coercivity and convexity to decide whether a minimum exists and whether a local minimum is global.
  • Apply the first-order (\(\nabla f = \mathbf 0\)) and second-order (Hessian) optimality conditions in \(n\) variables, including the Cholesky test for positive definiteness.
  • Explain why a minimizer can be computed only to about \(\sqrt{\epsilon}\) relative accuracy.

This page summarizes Heath §6.1–6.3 together with Stewart §14.7, CSc 302 meeting 20. The calculus (critical points, the Second Derivatives Test in two variables) is reviewed on the §14.7–14.8 page. Here it becomes the theory behind numerical optimization (meeting 21 and on).

1. Optimization problems (Heath §6.1)

Minimize an objective \(f: \mathbb R^n \to \mathbb R\) over a feasible set \(S\): \(\min_{\mathbf x \in S} f(\mathbf x)\). It is unconstrained if \(S = \mathbb R^n\), and constrained if \(S\) is described by equations \(\mathbf g(\mathbf x) = \mathbf 0\) and inequalities \(\mathbf h(\mathbf x) \le \mathbf 0\). Maximizing \(f\) is minimizing \(-f\).

  • \(\mathbf x^*\) is a global minimum if \(f(\mathbf x^*) \le f(\mathbf x)\) for all \(\mathbf x \in S\), and a local minimum if this holds for \(\mathbf x\) near \(\mathbf x^*\). Numerical methods find local minima. Finding a global one is hard in general, except for special classes such as convex problems.
  • Examples: least squares (meeting 11) minimizes \(\|A\mathbf x - \mathbf b\|_2^2\); physical systems settle at minimum energy; designs minimize cost or material.

2. Existence and uniqueness: coercivity and convexity (Heath §6.2–6.2.1)

  • Closed and bounded \(S\): a continuous \(f\) attains its minimum (Extreme Value Theorem, see the §14.7–14.8 review).
  • Unbounded \(S\): if \(f\) is coercive, meaning \(f(\mathbf x) \to +\infty\) as \(\|\mathbf x\| \to \infty\), a global minimum exists.
  • Convexity: \(f\) is convex if the chord between any two points of its graph lies on or above the graph: \(f(\alpha\mathbf x + (1-\alpha)\mathbf y) \le \alpha f(\mathbf x) + (1-\alpha)f(\mathbf y)\). Then every local minimum is global, and for strictly convex \(f\) the minimum is unique.
  • Test: a twice continuously differentiable \(f\) is convex on a convex set where its Hessian is positive semidefinite, and strictly convex where it is positive definite.

Examples

Example 1. Which are coercive on \(\mathbb R^2\)? (a) \(x^2 + y^4\), (b) \(x^2 - y^2\), (c) \(e^x + y^2\), (d) \((x - y)^2\).

Answer

(a) Yes: both terms grow without bound in every direction; global minimum 0 at the origin. (b) No: along the \(y\)-axis it goes to \(-\infty\), so there is no minimum. (c) No: as \(x \to -\infty\) with \(y = 0\) it tends to 0 without reaching it, so the infimum 0 is not attained. (d) No: it is 0 on the whole line \(y = x\); minima exist but are not unique.

Example 2. Show that \(f(x, y) = e^x + x^2 + 2xy + 3y^2\) is strictly convex, and find its global minimum.

Answer

\(H = \begin{bmatrix} e^x + 2 & 2 \\ 2 & 6\end{bmatrix}\) has \(\det H = 6e^x + 8 > 0\) and \(H_{11} > 0\) everywhere: positive definite, so \(f\) is strictly convex. \(\nabla f = \mathbf 0\) gives \(2x + 6y = 0\), so \(y = -x/3\), and \(e^x + 2x + 2y = e^x + \tfrac43 x = 0\). This equation has no closed-form solution; solving it numerically (a meeting 17–18 problem) gives \(x = -0.46915\), \(y = 0.15638\), \(f = 0.77227\). By convexity this is the unique global minimum.

3. Optimality conditions (Heath §6.2.2; Stewart §14.7)

For smooth \(f\) and an interior point \(\mathbf x^*\), Taylor's theorem in \(n\) variables gives \[ f(\mathbf x^* + \mathbf s) = f(\mathbf x^*) + \nabla f(\mathbf x^*)^T \mathbf s + \tfrac12\, \mathbf s^T H_f(\mathbf x^* + \alpha\mathbf s)\,\mathbf s, \qquad (H_f)_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}. \]

  • First order (necessary): at a local minimum \(\nabla f(\mathbf x^*) = \mathbf 0\); otherwise \(-\nabla f\) is a descent direction. Points with \(\nabla f = \mathbf 0\) are critical (stationary) points. Finding them means solving a nonlinear system, and the Hessian is the Jacobian of \(\nabla f\) (meeting 19).
  • Second order at a critical point. If \(H_f(\mathbf x^*)\) is:
    • positive definite: strict local minimum;
    • negative definite: strict local maximum;
    • indefinite: saddle point;
    • singular: no conclusion.
  • Testing definiteness: the eigenvalues of the symmetric matrix \(H\), all positive or all negative; or, cheaper, try a Cholesky factorization, which succeeds exactly when \(H\) is positive definite (meeting 10). For \(n = 2\) this is Stewart's \(D = f_{xx}f_{yy} - f_{xy}^2\) test.
  • Quadratics \(f(\mathbf x) = \tfrac12 \mathbf x^T A \mathbf x - \mathbf b^T \mathbf x\) with \(A\) symmetric: \(\nabla f = A\mathbf x - \mathbf b\) and \(H = A\). If \(A\) is positive definite, the unique minimizer solves the linear system \(A\mathbf x = \mathbf b\). Every smooth \(f\) looks like this near a minimum.

Examples

Example 3. Find and classify the critical point of \(f(x, y, z) = x^2 + y^2 + z^2 + xy + yz - 2x\).

Answer

\(\nabla f = (2x + y - 2,\ x + 2y + z,\ y + 2z) = \mathbf 0\) is the linear system \(\begin{bmatrix} 2 & 1 & 0 \\ 1 & 2 & 1 \\ 0 & 1 & 2\end{bmatrix}\mathbf x = \begin{bmatrix} 2 \\ 0 \\ 0\end{bmatrix}\), with solution \((1.5, -1, 0.5)\) and \(f = -1.5\). The Hessian is that constant matrix. Its eigenvalues \(2 - \sqrt2,\ 2,\ 2 + \sqrt2\) are all positive (equivalently, its Cholesky factorization succeeds): a strict local minimum, and since \(f\) is a convex quadratic, the global one.

Example 4. At the origin, \(f_1 = x^4 + y^4\) and \(f_2 = x^4 - y^4\) both have \(\nabla f = \mathbf 0\) and \(H = 0\). Classify them.

Answer

The Hessian test fails (\(H\) singular), so look at \(f\) directly. \(f_1 > 0\) away from the origin: a (global) minimum. \(f_2\) is positive along the \(x\)-axis and negative along the \(y\)-axis: a saddle point.

Example 5. Minimize \(f(\mathbf x) = \tfrac12\mathbf x^T A \mathbf x - \mathbf b^T\mathbf x\) with \(A = \begin{bmatrix} 4 & 1 \\ 1 & 3\end{bmatrix}\), \(\mathbf b = (1, 2)\).

Answer

\(A\) is symmetric positive definite (\(4 > 0\), \(\det A = 11 > 0\)), so the minimizer solves \(A\mathbf x = \mathbf b\): \(\mathbf x^* = \tfrac1{11}\begin{bmatrix} 3 & -1 \\ -1 & 4\end{bmatrix}\begin{bmatrix} 1 \\ 2\end{bmatrix} = \left(\tfrac1{11}, \tfrac7{11}\right)\), with \(f^* = -\tfrac12 \mathbf b^T\mathbf x^* = -\tfrac{15}{22}\). Minimizing a convex quadratic is the same as solving an SPD linear system.

4. Sensitivity and conditioning (Heath §6.3)

Near a minimum \(f(x^* + h) \approx f(x^*) + \tfrac12 f''(x^*)h^2\): the function is flat. If \(f\) can be computed only to within \(\epsilon\), every \(x\) with \(\tfrac12 |f''| h^2 \lesssim \epsilon\) looks equally good, so the minimizer is determined only to \[ |\hat x - x^*| \approx \sqrt{2\epsilon / |f''(x^*)|} . \] With \(\epsilon \approx \epsilon_{\text{mach}}|f|\), that is about \(\sqrt{\epsilon_{\text{mach}}} \approx 10^{-8}\) relative accuracy: half the digits of a root of an equation, just as for a multiple root (meeting 17). Do not ask an optimizer for a tolerance tighter than about \(10^{-8}\) in \(\mathbf x\) when it uses only \(f\) values. In \(n\) dimensions, the conditioning of \(H_f(\mathbf x^*)\) also matters: elongated level sets mean that some directions are determined much less accurately than others.

Example 6. For \(f(x) = x^2 - 2x + 2\) (minimum 1 at \(x = 1\)), compare \(f(1)\) and \(f(1 + 10^{-8})\) in double precision.

Answer

The exact difference is \(10^{-16}\), below the spacing \(2.2\times10^{-16}\) of floating-point numbers near 1, so both are computed as exactly 1.0. Points up to about \(1.5\times10^{-8}\) from the minimizer cannot be told apart by their \(f\) values (at \(1 + 3\times10^{-8}\) the computed difference \(f - 1\) is \(8.9\times10^{-16}\), four spacings).

  1. What is the difference between a local and a global minimum? Which one do numerical methods find?
