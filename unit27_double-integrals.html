1. Double integrals and Fubini's theorem (Stewart §15.1)

Over a rectangle \(R = [a, b] \times [c, d]\), the double integral \(\iint_R f\,dA\) is the volume under the surface \(z = f(x, y)\), the limit of Riemann sums. For continuous \(f\), Fubini's theorem lets us integrate one variable at a time, in either order: \[ \iint_R f(x, y)\,dA = \int_a^b \!\!\int_c^d f(x, y)\,dy\,dx = \int_c^d \!\!\int_a^b f(x, y)\,dx\,dy . \] Applications (Stewart §15.4): for a lamina with density \(\rho(x, y)\), the mass is \(m = \iint \rho\,dA\) and the center of mass is \(\bar x = \frac1m \iint x\rho\,dA\), \(\bar y = \frac1m \iint y\rho\,dA\). For random variables with joint density \(f\), \(P\bigl((X, Y) \in D\bigr) = \iint_D f\,dA\).

Examples

Example 1. Evaluate \(\iint_R (x + 2y)^2\,dA\) on \(R = [0, 1]^2\) exactly, then with the 2×2 midpoint rule and with the 2×2 Gauss rule.

Answer

Expand: \(x^2 + 4xy + 4y^2\) integrates to \(\tfrac13 + 1 + \tfrac43 = \tfrac83 = 2.6667\). Midpoint at \((\tfrac14, \tfrac34)^2\), each with weight \(\tfrac14\): \(\tfrac14(0.5625 + 3.0625 + 1.5625 + 5.0625) = 2.5625\), error \(-0.104\). Gauss at \(\tfrac12 \pm \tfrac{1}{2\sqrt3}\) in each direction: \(2.6667\), exact, because the 2-point Gauss rule is exact for degree 3 in each variable.

Example 2. A plate occupies \([0, 1] \times [0, 2]\) with density \(\rho = 1 + y^2\). Find its mass and center of mass.

Answer

\(m = \int_0^1\!\int_0^2 (1 + y^2)\,dy\,dx = 2 + \tfrac83 = \tfrac{14}{3}\). \(\bar x = \tfrac12\) by symmetry (\(\rho\) does not depend on \(x\)). \(\iint y\rho\,dA = \int_0^2 (y + y^3)\,dy = 2 + 4 = 6\), so \(\bar y = 6/(14/3) = \tfrac97 = 1.286\): above the middle, where the plate is denser.

2. Change of variables; polar coordinates (Stewart §15.3, §15.9)

For a one-to-one map \(x = x(u, v)\), \(y = y(u, v)\) from a region \(S\) onto \(D\), \[ \iint_D f(x, y)\,dA = \iint_S f\bigl(x(u, v), y(u, v)\bigr)\,\left|\frac{\partial(x, y)}{\partial(u, v)}\right| du\,dv, \qquad \frac{\partial(x, y)}{\partial(u, v)} = \det\begin{bmatrix} x_u & x_v \\ y_u & y_v \end{bmatrix}. \] For polar coordinates \(x = r\cos\theta\), \(y = r\sin\theta\), the Jacobian is \(r\), so \(dA = r\,dr\,d\theta\). Numerically, the change of variables turns a disk into a rectangle in \((r, \theta)\), where product rules work and the boundary no longer cuts through the grid.

Example

Example 3. Compute \(\iint_D \frac{dA}{1 + x^2 + y^2}\) over the unit disk exactly in polar coordinates. Then compare a 4-point Gauss rule in \(r\) with the midpoint rule on a \(k \times k\) grid over \([-1, 1]^2\) that counts only cells whose centers lie in the disk.

Answer

\(\int_0^{2\pi}\!\int_0^1 \frac{r}{1 + r^2}\,dr\,d\theta = 2\pi \cdot \tfrac12\ln 2 = \pi\ln 2 = 2.177586\). In polar form the \(\theta\) integral is exact, and 4 Gauss points in \(r\) give \(2.177612\), error \(2.6\times10^{-5}\). The Cartesian grid has errors \(3.0\times10^{-2}\), \(9.2\times10^{-3}\), \(1.4\times10^{-4}\) for \(k = 10, 40, 160\): slow and erratic, because the disk's edge cuts cells arbitrarily (the integrand times the indicator is discontinuous).

3. Product rules and their cost (Heath §8.4.3)

A tensor-product (Cartesian product) rule applies a 1-D rule in each direction: \[ \iint_R f\,dA \approx \sum_{i=1}^n \sum_{j=1}^n w_i v_j\, f(x_i, y_j). \] It inherits the 1-D rule's order: the composite midpoint rule with \(k\) panels per side has error \(O(h^2)\) with \(h = 1/k\), using \(N = k^2\) points, so the error is \(O(N^{-1})\). In \(d\) dimensions the same rule needs \(N = k^d\) points for error \(O(N^{-2/d})\): the curse of dimensionality. Other 2-D options: nested adaptive 1-D routines (scipy.integrate.dblquad), and non-product rules on triangles for general regions.

4. Monte Carlo integration (Heath §8.4.4)

Sample \(N\) points \(\mathbf x_k\) uniformly in a region \(\Omega\) of area (volume) \(|\Omega|\), and use \[ \iint_\Omega f\,dA \approx |\Omega| \cdot \frac1N \sum_{k=1}^N f(\mathbf x_k), \qquad \text{standard error} \approx |\Omega|\,\frac{\sigma}{\sqrt N}, \] where \(\sigma\) is the standard deviation of \(f\) on \(\Omega\), estimated from the samples. The error is random, decreases only like \(N^{-1/2}\) (100 times more points for one more digit), and does not depend on the dimension. In 1-D or 2-D Monte Carlo loses to quadrature; beyond about 4–5 dimensions, or for irregular regions, it wins. To fix the random numbers, seed the generator: rng = np.random.default_rng(302).

Examples

Example 4. Estimate \(\pi\) by Monte Carlo: \(\pi/4\) is the probability that a uniform point in \([0, 1]^2\) lands in the quarter disk \(x^2 + y^2 \le 1\). What standard error do you expect with \(N = 10^4\) points? How many points for 4 correct digits?

Answer

Here \(f\) is the indicator of the quarter disk: its mean is \(p = \pi/4\) and \(\sigma = \sqrt{p(1 - p)} = 0.411\). The estimate \(4\bar f\) has standard error \(4\sigma/\sqrt N = 0.0164\) for \(N = 10^4\). One seeded run (seed 302) gave \(3.12\), \(3.13\), \(3.1406\) for \(N = 10^2, 10^4, 10^6\); the errors \(0.022\), \(0.012\), \(0.0010\) are within one or two standard errors. For an error of \(5\times10^{-5}\) you need \(N \approx (4\sigma/5\times10^{-5})^2 \approx 10^9\) points, which is why nobody computes \(\pi\) this way.

Example 5. A product midpoint rule with 10 points per direction on the unit cube \([0, 1]^d\): how many evaluations for \(d = 2, 6, 10\)? How many does Monte Carlo need for error \(10^{-3}\) if \(\sigma = 1\)?

Answer

\(10^2\), \(10^6\), \(10^{10}\) evaluations, with error \(O(h^2) = O(10^{-2})\) in every case. Monte Carlo needs \(N = (\sigma/10^{-3})^2 = 10^6\) in any dimension. At \(d = 2\) quadrature is far cheaper; at \(d = 10\) Monte Carlo is the only option.
